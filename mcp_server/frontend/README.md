# SketchKit Agent

A conversational interface for SketchKit - AI-powered sketch processing tools.

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Type-Check, Compile and Minify for Production

```sh
npm run build
```

### Lint with ESLint

```sh
npm run lint
```

## Features

- 💬 Chat-based interface for sketch processing
- 🎨 Intent recognition for automatic task routing
- 📸 Multi-modal input (text + images)
- 🔄 Real-time result preview
- 📦 Integration with all SketchKit modules
